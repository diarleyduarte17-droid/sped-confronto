# Confronto SPED Fiscal

Núcleo educacional para confrontar documentos C100 do SPED Fiscal contra uma base autorizada de NF-e. O resultado são divergências explicáveis, não um parecer fiscal nem uma retificação automática.

O exemplo cobre chaves, totais e presença do documento. Expanda-o por regra, com fixtures anonimizadas e revisão de contador/área fiscal.

```bash
npm install
npm run check
```

Use [AGENTS.md](./AGENTS.md) para dar à sua IA contexto e limites da evolução.

## 🇬🇧 English

**SPED Fiscal cross-check.** Educational core that compares C100 documents from SPED Fiscal against an authorized NF-e base. The output is explainable discrepancies, not a tax opinion or automatic rectification. Covers keys, totals and document presence.

```bash
npm install
npm run check
```
